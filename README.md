#

#Τιμολόγια σε εκκρεμότητα
#Customers (Πελάτες)
#Διαχείριση πελατολογίου. Μπορείς να:

Προσθέσεις πελάτη (όνομα, email, τηλέφωνο, διεύθυνση, ΑΦΜ, σημειώσεις)
Επεξεργαστείς / διαγράψεις υπάρχοντα
Κάνεις αναζήτηση με search bar
Products / Services (Προϊόντα)
Τιμοκατάλογος της εταιρείας. Μπορείς να:

Προσθέσεις προϊόν ή υπηρεσία
Ορίσεις τιμή, ΦΠΑ (%), απόθεμα (stock)
Επεξεργαστείς / διαγράψεις
Κάνεις αναζήτηση
Invoices (Τιμολόγια)
Έκδοση και παρακολούθηση τιμολογίων. Μπορείς να:

Δημιουργήσεις τιμολόγιο επιλέγοντας πελάτη, ημερομηνία, κατάσταση (draft / unpaid / paid / cancelled)
Προσθέσεις πολλαπλές γραμμές (line items) — επιλέγεις προϊόν και αυτόματα συμπληρώνεται τιμή και ΦΠΑ
Δεις σύνολα σε real-time (Subtotal / VAT / Total)
Ανοίξεις printable έκδοση κάθε τιμολογίου σε νέα καρτέλα
Expenses (Έξοδα)
Καταγραφή εξόδων/αγορών. Μπορείς να:

Καταχωρήσεις έξοδο (προμηθευτής, κατηγορία, ποσό, ΦΠΑ, ημερομηνία, σημειώσεις)
Επεξεργαστείς / διαγράψεις
Tasks (Εργασίες)
Εσωτερική λίστα εργασιών (to-do). Μπορείς να:

Δημιουργήσεις task με τίτλο, περιγραφή, προθεσμία
Θέσεις κατάσταση: pending / in_progress / done
Αναθέσεις task σε χρήστη της εταιρείας
Reports (Αναφορές)
Μηνιαία οικονομική αναφορά. Μπορείς να:

Επιλέξεις μήνα και να δεις: έσοδα, έξοδα, εκτιμώμενο κέρδος
Δεις ανάλυση πωλήσεων ανά πελάτη
Κατεβάσεις την αναφορά ως CSV αρχείο
